🎓 Student Grade Management System Python (CLI Based)
📌 Project Description:
This is a Command-Line Interface (CLI) based Student Grade Management System developed using Python. It enables users to add, update, delete, and view student records along with their grades. The data is stored in memory using a Python dictionary, making it a great project for beginners to understand data structures, functions, and control flow in Python.

🚀 Key Features:
Add Student – Insert a new student with their grade.
Update Student – Modify an existing student's grade.
Delete Student – Remove a student by name.
View All Students – Display all student names and their grades.
Menu Loop – Interactive CLI menu runs until the user chooses to exit.
Input Validation – Basic checks for student presence before updates/deletions.

🛠️ Technologies Used:
Language: Python 3.x
Interface: CLI (Command Line Interface)
Libraries: None (Only core Python)
